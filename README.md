# MLDev Experiment Agent

## Назначение

Проект разрабатывает AI-агента, который превращает существующий
ML/Data Science проект в воспроизводимый эксперимент.

Агент использует только уже существующий код проекта и не придумывает новую
математическую или ML-логику.

## Вход

Агент получает:

1. путь к существующему ML/Data Science проекту;
2. текстовое описание требуемого эксперимента.

## Результат

Агент должен создать:

1. формальный план эксперимента;
2. последовательный MLDev pipeline;
3. DVC-конфигурацию для версионирования данных;
4. результаты запуска, логи и metadata;
5. отчёт о выполненных проверках или список нерешённых требований.

## Главное ограничение

Если в исходном проекте нет кода для требуемой операции, агент обязан
остановиться и сообщить об этом. Он не должен самостоятельно реализовывать
отсутствующую вычислительную логику.
