# Запрос эксперимента

Проверить две гипотезы на одной подготовленной версии данных.

Сначала получить исходный набор данных существующей командой проекта. Затем
один раз подготовить данные и сохранить результат в `data/prepared.csv`.

## Гипотеза 1

Среднее значение столбца `value` больше `5`.

Проверку выполнить существующим кодом из
`notebooks/hypothesis_1.ipynb`.

## Гипотеза 2

Дисперсия значений столбца `value` меньше `10`.

Проверку выполнить существующим кодом из
`notebooks/hypothesis_2.ipynb`.

## Ограничения

1. Обе гипотезы используют один и тот же `data/prepared.csv`.
2. Подготовка данных выполняется только один раз.
3. Стадии выполняются последовательно:
   `acquire_data`, `prepare_data`, `hypothesis_1`, `hypothesis_2`.
4. Результат каждой гипотезы сохраняется отдельно:
   `runs/<run_id>/hypothesis_<n>/result.json`.
